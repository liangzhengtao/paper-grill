# Contributing to paper-grill

Thank you for your interest in contributing to paper-grill! This document provides guidelines and instructions for contributing.

## How to Contribute

### Reporting Issues

If you find a bug, have a suggestion, or want to request a new skill, please open an issue:

1. Check if the issue already exists
2. Use the appropriate issue template
3. Provide as much detail as possible

### Submitting Changes

1. Fork the repository
2. Create a new branch for your changes
3. Make your changes
4. Test your changes
5. Submit a pull request

### Adding New Skills

To add a new review skill:

1. Create a new `.md` file in the appropriate directory
2. Follow the skill template structure
3. Include all required sections:
   - When to Use
   - Review Framework
   - Scoring Rubric
   - Review Templates
   - Example Reviews (good and bad)
   - Common Mistakes to Avoid
   - 中文版本
